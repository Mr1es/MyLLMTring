# 🐋 MyLLMTring

### 张嘉润 · 人工智能协会创智部二面大题一实战项目：大肥鱼桌面宠物

  *技术路线：本地qwen模型 ——> ollama（小题1） ——> dify（小题2，我觉得这也算一个agent，毕竟人格设置是在这里完成的） ——> shim（用于开源桌宠和本地模型之间的协议交换） ——> 开源桌宠*
