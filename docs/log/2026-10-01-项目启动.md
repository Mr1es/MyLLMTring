## 关键决策记录

1. **智能体平台选扣子（Coze）而非 Dify**
   - 原因：Dify 本地部署依赖 Docker，对当前零基础阶段成本过高；扣子零部署、国内访问稳定，
     提示词 / 知识库 / API 能力满足题目要求。
2. **模型选 Qwen3:8b（初版曾定为 Qwen2.5:7b，经硬件实测与社区验证后修正）**
   - 演进过程：Qwen2.5:7b → Qwen3:8b → 评估 Qwen3.5:9b → 回退 Qwen3:8b。
   - 原因：Qwen3:8b Q4 约 5.2GB，在 8GB 显存（可用约 6.15GB）下有余量，确定性最高；
     Qwen3.5:9b 体积虽相近，但 Ollama 存在显存过度预留现象，笔记本可用显存偏小，
     存在部分层 offload 到 CPU 导致降速的风险，故采用更稳妥的 8b，9b 列为备选。
3. **CLI 仅用 Python 标准库（urllib）**
   - 原因：避免 pip 安装第三方依赖，减少环境问题；先跑通链路再谈工程化。

## 卡点记录

- **GitHub 直连被墙**：`git clone` 报 `Failed to connect to github.com:443`。
  - 解决方案：push 时开启 Clash **系统代理**（切勿用 TUN 虚拟网卡模式，会劫持全机流量导致
    其他连接异常），git 单独配置 `http.proxy=http://127.0.0.1:7897`，仅 git 流量走代理。
